KWKMA Website
==============

Run:
1. Open terminal in this folder.
2. npm init -y
3. npm install express
4. node server/server.js
5. Open http://localhost:3000

Assets already included:
- images/logo.png
- images/banner1.jpg
- images/banner2.jpg
- images/banner3.jpg
- images/teacher.jpg

Firebase is intentionally not connected yet.
